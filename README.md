# Habit Tracker

A modern and responsive Habit Tracker application designed to help users build good habits, maintain consistency, and monitor daily progress.

## Features
- Daily habit tracking with check/uncheck.
- Real-time progress ring and streak counter.
- Monthly calendar with completion status.
- Add, edit, and delete habits.
- Custom habit icons and categories.
- Statistics with weekly and monthly charts.
- 8 unlockable achievement badges.
- Profile and settings management.
- Reset and rename options.

## UI & Design
- Premium dark theme.
- Terracotta orange accents.
- Clean and modern interface.
- Smooth interactions and responsive layout.

## Project Goal
To make habit building easier through simple tracking, visual progress, and achievement-based motivation.

**Build Better Habits. Stay Consistent.**
